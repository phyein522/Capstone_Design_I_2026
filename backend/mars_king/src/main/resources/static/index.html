이미지 속 개인정보,
자동으로 지워드립니다

얼굴인식과 OCR 기술로 이미지 내 얼굴과 텍스트 개인정보를 감지하고, 좌표 기반으로 자동 마스킹 처리합니다.

Features  ·  Mark-It의 기능
기능 01
🤖
자동 탐지

EasyOCR을 활용하여 이미지 속 텍스트 영역을 자동 검출합니다.

기능 02
🌐
설치 없는 웹 서비스

앱 설치도 로그인도 비용도 필요 없습니다. 기존 솔루션들이 기업용 SW 설치나 SDK 도입을 요구하는 것과 달리 브라우저에서 바로 누구나 사용할 수 있습니다.

기능 03
🎯
선택적 마스킹

감지된 항목을 일괄 처리하지 않고 사용자가 직접 항목별로 마스킹 여부를 선택할 수 있습니다. 필요한 정보만 골라서 처리하는 유연한 제어가 가능합니다.

기능 04
⬇️
즉시 다운로드

마스킹 처리된 이미지를 바로 저장할 수 있습니다. 업로드된 원본 이미지는 서버에 보관되지 않아 개인정보 유출 걱정 없이 안전하게 사용할 수 있습니다.
